# Sabong web frontend

Svelte 5 + TypeScript + Vite UI demo for the Sabong Gamefowl Management and Record System. The interface follows the SRS and SDD in the parent folder and uses the mobile app's dark red and gold visual direction.

## Run

```bash
npm install
npm run dev
```

Use **Explore the UI demo** on the sign-in screen to enter. The demo includes bird profiles and pedigree, breeding records, care and reminders, supply levels, matches and brackets, and printable reports. Forms and actions update in-memory sample data. Refreshing resets the sample records.

## Check

```bash
npm run check
npm run build
```

This is frontend only. Sign-in, registration, password recovery, data storage, AI features, and email delivery are visual workflows with no backend connection.
